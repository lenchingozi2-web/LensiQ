# Live Class outcomes

- [x] **Legacy Word uploads work across lecture flows.** Accept and parse real `.doc` files as well as PDF, DOCX, PPTX, and TXT; normalize MIME variants and detect extensionless Word files by binary signature while keeping the 20-file/50 MB limits clear.
- [x] **The Live Class canvas is premium and full-bleed.** `/voice?mode=class` badges into a dark medical-lab stage with restrained chrome and a centered frosted-glass LiveKit dock.
- [x] **Visuals follow the active concept, not a fixed course theme.** Tutor transcripts switch between relevant anatomy, pharmacology targets, chemical-pathology/ADME whiteboards, physiology simulations, pathology or histology/cytology schematics, supplied media, and explanation-specific concept boards; unrelated prior visuals do not linger.
- [x] **The session carries a versioned visual protocol.** It supplies exact approved assets, source and ligand caveats, visual commands, and interaction events; the client also routes from live speech so the stage still changes when the tutor omits an explicit visual command.
- [x] **Learners can explore the lesson.** Rotate/zoom models, focus structures, adjust physiology variables, and select/zoom whiteboard concepts; learner interaction events are emitted for tutor synchronization.
- [ ] **A useful asset set is seeded with storage headroom preserved.** Upload valid anatomy/system models, pharmacology structures, and clearly labelled educational histology/cytology/pathology schematics with per-asset rights metadata under the conservative project-storage budget.
